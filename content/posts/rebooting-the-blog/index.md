When I was younger I had a personal website where I shared projects, ideas, and creative work, and it was a lot of fun. So, I'm bringing it back. This is hosted on GitHub pages or maybe CloudFlare, I can't remember, and it's built using Hugo.

The big internet sharing platforms explicitly make it harder to share things like this with other people, so this is a tiny little protest against the current state of the internet and the user-hostile platforms that have apparently taken control. 🖕
